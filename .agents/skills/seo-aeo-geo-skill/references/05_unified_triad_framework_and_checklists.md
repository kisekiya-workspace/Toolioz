# Unified Search Triad Framework & Master Checklist

This reference presents the 3-Layer SEO-AEO-GEO Triad, the 5-Step AI-Native Content Optimization Workflow, and the Master 67-Point Checklist enriched with all explicit guidelines, limits, and percentages.

---

## 1. The SEO-AEO-GEO Triad Connection

```
                        +-----------------------+
                        |       GEO LAYER       |
                        | Cites & References    |
                        | ChatGPT, Perplexity   |
                        +-----------+-----------+
                                    |
                        +-----------+-----------+
                        |       AEO LAYER       |
                        | Extracts & Summarizes |
                        | AI Overviews, Snippets|
                        +-----------+-----------+
                                    |
                        +-----------+-----------+
                        |       SEO LAYER       |
                        | Baseline Foundation   |
                        | Crawlability, Trust   |
                        +-----------------------+
```

1. **SEO Foundation**: Baseline crawlability, SSL security, site speed (<2s), mobile responsiveness, domain authority (E-A-T), and organic search rankings.
2. **AEO Layer**: Accessibility in answer-driven search (Google AI Overviews, Bing Copilot) using lead-with-the-answer formatting, lists, tables, and JSON-LD schema.
3. **GEO Layer**: Trusted reference in generative output (ChatGPT, Perplexity, Gemini, Claude) through primary research, third-party validation (Reddit, Quora, LinkedIn, Wikipedia), and topical authority.

## 3. Master 67-Point SEO / AEO / GEO Checklist

### Strategy, Audits, & Tools
- [ ] 1. Develop a long-term unified SEO/AEO/GEO strategy and adjust it based on analytics data.
- [ ] 2. Setup Google Analytics, Google Search Console, and Morningscore to track traffic, indexing, and rankings.
- [ ] 3. Perform competitor analysis examining competitors' keywords, content strategies, and backlink profiles.
- [ ] 4. Perform comprehensive quarterly SEO audits covering Strategic, Technical, Page-Level, Content, UX/UI, Link, and Citation dimensions.
- [ ] 5. Conduct keyword research discovering high-volume short-tail keywords and high-conversion long-tail key phrases (using Google Keyword Planner and Search Bar suggestions).
- [ ] 6. Prevent keyword cannibalization—ensure no two pages compete for the exact same focus keyword.
- [ ] 7. Include common misspellings of focus keywords (e.g. `"camkorder, kamcorder, camcorder"`) in internal keyword target lists.

### Technical SEO & Infrastructure
- [ ] 8. Verify HTTPS encryption (SSL certificate) across 100% of website URLs.
- [ ] 9. Check page crawlability and indexation in Google Search Console's Coverage tab.
- [ ] 10. Use GSC's Inspect URL feature to verify how Google's rendering engine renders HTML.
- [ ] 11. Generate a simple, organized `sitemap.xml` and submit it to Google Search Console.
- [ ] 12. Validate `robots.txt` (`example.com/robots.txt`) to ensure search spiders are not blocked from critical content.
- [ ] 13. Maintain page load speed **UNDER 2 SECONDS** (test via Google PageSpeed Insights).
- [ ] 14. Ensure 100% mobile-first responsiveness (verify via Google Mobile-Friendly Test).
- [ ] 15. Set up browser caching and implement server-side caching.
- [ ] 16. Host on a reliable server to eliminate downtime; upgrade server runtime to **PHP 7.0 or higher**.
- [ ] 17. Use clean permalink structures: `example.com/postname` or `example.com/category/post-name` (NEVER default `?p=123`).
- [ ] 18. **DO NOT use Flash or unnecessary render-blocking JavaScript files**.
- [ ] 19. Minify CSS, HTML, and JavaScript files.
- [ ] 20. Install SEO plugins (Yoast SEO or Rank Math); delete unused plugins and update active plugins regularly.
- [ ] 21. Create and install a site favicon (`.ico`).
- [ ] 22. Ensure accessible navigation menus on both desktop and mobile.

### On-Page HTML & Meta Tags
- [ ] 23. URL structure maximum **75 characters**, lowercase, hyphen-separated (`-`). **Replace underscores with hyphens**.
- [ ] 24. **DO NOT use stop words like `"is"` or `"the"` in URLs**.
- [ ] 25. Catchy, short title tag maximum **60 characters**, with focus keywords upfront.
- [ ] 26. **DO NOT include punctuation marks or special characters at the beginning of titles**.
- [ ] 27. **Avoid promotional superlatives like `"best"`, `"cheapest"`, or `"great"` in titles**. Point broad category terms to homepage or category pages.
- [ ] 28. Meta description maximum **150 characters with spaces** (under 150-160 chars) with a clear CTA.
- [ ] 29. **Meta descriptions MUST be written in THIRD PERSON—STRICTLY AVOID `"me"`, `"my"`, `"you"`, `"your"`**.
- [ ] 30. Exactly **ONE H1 tag per page**, surrounding post title, with focus keyword as close to the beginning as possible.
- [ ] 31. **ABOUT 80% OF H2 - H6 SUBHEADINGS SHOULD CONTAIN YOUR KEYWORD**.
- [ ] 32. Place related keywords **AS EARLY AS POSSIBLE** in H2 and H3 subheadings.
- [ ] 33. Configure OpenGraph (`og:image`) and Twitter Card (`twitter:image`) social sharing tags.

### Editorial Quality & Formatting
- [ ] 34. **Google puts more weight on the first 100-150 words**—place primary keywords, core thesis, and main ideas in the first 100-150 words.
- [ ] 35. Produce comprehensive longform content (**over 1,000 words**), prioritizing quality, relevance, and intent.
- [ ] 36. **DO NOT USE PUNS OR WORDPLAY**—search engine Spiders scan keywords and do not understand humor.
- [ ] 37. Break text into small paragraphs/chunks, use bulleted lists, and use **bold text** to highlight key points.
- [ ] 38. Eliminate all spelling and grammar errors.
- [ ] 39. Publish research/expert content (statistics, data, industry studies, infographics, white papers, surveys) to earn natural backlinks.
- [ ] 40. Maintain evergreen content freshness; delete old, outdated, or duplicate content.
- [ ] 41. Create embeddable visual content (infographics, charts) with a link back to your site.

### Image & Video SEO
- [ ] 42. Compress images to **UNDER 100KB** while preserving visual quality.
- [ ] 43. Save photographic images as **`.JPEG`** (not `.TIFF`), graphics as **`.PNG`** (for transparency), icons/logos as **`.SVG`**.
- [ ] 44. Resize images to display dimensions **BEFORE uploading**.
- [ ] 45. Use descriptive image titles in **LOWERCASE**.
- [ ] 46. Add image `<alt>` tags **NOT exceeding 65 characters with spaces**, including focus keywords (no keyword stuffing).
- [ ] 47. Use image captions and verify alt tags using browser tools like *Web Developer Extension*.
- [ ] 48. Optimize video content with surrounding descriptive text (title, description, captions, tags).

### Linking Strategy
- [ ] 49. Insert internal links using descriptive keyword anchor text (**NEVER use `"click here"`**).
- [ ] 50. Target incoming backlinks to **deep links within your site** (not just homepage).
- [ ] 51. Include 2 to 3 internal links to related posts, linked tags to related content, and links to category pages.
- [ ] 52. **DO NOT link to competitor pages covering a similar topic** (you cannot outrank a competitor when linking to them).
- [ ] 53. Include **2 to 4 outbound links every 1,000 words** to authoritative sources.
- [ ] 54. Set outbound links to open in a new window (`target="_blank"`).
- [ ] 55. ALWAYS use standard HTML **`<a>`** tags for links—**NEVER use JavaScript**.
- [ ] 56. Fix dead/broken links regularly using tools like *Broken Link Checker*.

### Answer Engine & Generative Engine Optimization (AEO & GEO)
- [ ] 57. Frame H2/H3 subheadings as natural user questions.
- [ ] 58. Open sections with a 1-sentence direct answer block (25-45 words).
- [ ] 59. Provide comparison tables, ordered lists (`1. 2. 3.`), and glossary definitions.
- [ ] 60. Inject `FAQPage` and `HowTo` JSON-LD schema markup.
- [ ] 61. Include screenshots, charts, and product diagrams with alt text (AI summaries keep images visible longer than text).
- [ ] 62. Publish primary research, original data, and quotable definitions.
- [ ] 63. Attribute content to expert authors with clear bio, credentials, and external links (E-E-A-T).
- [ ] 64. Build off-page presence and brand mentions on **Reddit, Quora, LinkedIn, and Wikipedia**.
- [ ] 65. Execute query fan-out topic clusters to establish topical authority across connected pages.
- [ ] 66. Verify 100% NAP consistency (Name, Address, Phone) across Google Business Profile and local directories.
- [ ] 67. Monitor AI citation share, zero-click snippet presence, and LLM referral traffic (converting at **4.4x rate**).
