## 3. Core Triad Framework Overview

```
                        +-----------------------+
                        |       GEO LAYER       |
                        | Cites & References    |
                        | ChatGPT, Perplexity   |
                        +-----------+-----------+
                                    |
                        +-----------+-----------+
                        |       AEO LAYER       |
                        | Extracts & Summarizes |
                        | AI Overviews, Snippets|
                        +-----------+-----------+
                                    |
                        +-----------+-----------+
                        |       SEO LAYER       |
                        | Baseline Foundation   |
                        | Crawlability, Trust   |
                        +-----------------------+
```

Modern search is a three-layer discipline:
1. **SEO Foundation**: Secures baseline crawlability, site performance (<2s), domain authority (E-A-T), and traditional SERP rankings.
2. **AEO Layer**: Prepares content for instant extraction in answer features (Google AI Overviews, featured snippets) using concise lead-with-the-answer formatting (25-45 words) and JSON-LD schema.
3. **GEO Layer**: Establishes reference-grade authority, primary data, and third-party web presence (Reddit, Quora, LinkedIn, Wikipedia) so LLMs cite your brand in conversational answers.

## 4. Quick Rules & Micro-Tips Cheatsheet

- **Site Load Speed**: Must be **under 2 seconds**.
- **Mobile First**: Google ranks based **only** on mobile responsiveness.
- **Title Tag**: Max **60 characters**, keywords upfront, **no special characters at beginning**, **no superlatives** ("best", "cheapest").
- **Meta Description**: Max **150 characters with spaces**, **MUST be in THIRD PERSON** (NO `"me"`, `"my"`, `"you"`, `"your"`).
- **H1 Tag**: Exactly **ONE** H1 tag per page surrounding title, keyword upfront.
- **Subheadings (H2-H6)**: **~80% MUST contain target keywords**, placed as early as possible.
- **First 100-150 Words**: Google weighs the first 100-150 words most heavily—place focus keywords, core thesis, and primary answers here.
- **Text Formatting**: **Replace underscores with hyphens in URLs**. **NO PUNS OR WORDPLAY** (robots do not understand humor).
- **Outbound Links**: Include **2 to 4 outbound links per 1,000 words** to reputable sources (`target="_blank"`, standard `<a>` tags, no JavaScript). **Do NOT link to direct competitors**.
- **Image SEO**: Compress **<100KB**, save photos as `.JPEG`, graphics as `.PNG`, logos as `.SVG`. Resize BEFORE uploading. Lowercase filenames. **Alt text max 65 characters**.
- **AEO Direct Answer**: 1-2 sentence direct answer block (25-45 words) directly below question heading.
- **LLM Citation Value**: Visitors from LLM referrals convert at **4.4x higher rate** than traditional search visitors.
- **Indexing Truth**: "Crawled - not indexed" is an authority issue, not a technical glitch. Simply updating dates (2025 to 2026) without content depth fails.
- **Server-Side Rendering (SSR)**: Mandatory for AI crawlers (PerplexityBot, GPTBot, ClaudeBot).
- **Atomic Answers**: 50-100 word standalone answer blocks under H2 headings for instant AI extraction.
- **GSC High-Impression/Low-CTR Hack**: Rewrite titles and add top answer blocks to capture clicks on high-ranking pages.
- **Share of Model (SoM)**: Measure brand citation rate across ChatGPT, Perplexity, Gemini, and Claude alongside keyword ranks.
